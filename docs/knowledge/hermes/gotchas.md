# hermes 함정·이력

헤르메스 **자체**(스크립트·현황판·규칙 문서·스킬) 작업에서 밟은 함정. 서비스 레포 함정은 각 레포 `gotchas.md` 에 적는다.
헤르메스가 `repo: hermes` 작업(현황판 [정비] 탭)을 시작할 때 읽는다. 항목은 학습 후보를 사용자가 현황판 [학습] 탭에서 [넣기] 한 것만 들어온다(기준 `docs/knowledge/common/learning.md`).

## 학습

학습 루프로 들어온 줄 — 현황판 [학습] 탭에서 수정·삭제한다. 쉬운 설명은 `docs/knowledge/learned/`
