# 팀 공통 보고 규칙

에이전트 완료 보고는 항상 아래 4항목. 헤르메스는 이걸 그대로 취합해 사용자에게 전달한다.

1. **변경 파일 목록** (경로, 레포/앱/레이어별)
2. **구현 요약** — 계획서 항목별 완료 / 미완료 / 다르게 한 것과 이유
3. **검증 결과** — 실행한 명령과 결과 그대로. 실패는 원문 포함. **실행하지 못한 검증은 "실행 못 함"이라고 적는다** (통과한 것처럼 쓰지 않는다)
4. **남은 위험·확인 필요** — 범위 밖 수정 필요, 추측으로 처리한 부분, 다른 서비스 영향, 후속 작업

원칙:
- 불확실한 내용은 "추측입니다", "확실하지 않습니다"라고 명시
- 한국어로 소통, 코드 주석도 한국어. 영어는 코드·파일명·기술 용어만
- 같은 오류 3회 반복, 범위 밖 수정 필요, 규칙 충돌은 진행하지 말고 보고
