우선 — 깨지면 얼마나 큰일인가

P0
핵심. 깨지면 서비스가 안 된다(가입·로그인·신청·결제·질문·계산 결과). 배포 전에 반드시 본다
P1
주요 기능. 깨지면 불편하거나 일부가 막히지만 핵심 흐름은 산다(입력 검증·조회·주요 버튼·쿼리 보존)
P2
부가·드문 경우. 연출·문구·특정 조건·경계 입력(배너 교체·파트너 진입·500자 입력)

분류 — 무엇을 확인하나

스모크
화면이 열리고 깨지지 않는지
가드
로그인·본인인증·쿼리 조건에 따라 맞는 곳으로 보내는지
흐름
누르고 입력하며 끝까지 따라가는지
계산
입력 → 기대 숫자가 맞는지(계산기)
에러
잘못된 입력·실패 응답에서 안내가 맞는지
반응형
모바일·데스크톱 폭에서 배치가 맞는지
SEO
메타·사이트맵·색인 설정

자동화 — 어떻게 돌리나

스모크
주소만 바로 열어 본다
씬
scripts/qa/scenarios 의 단계대로 누르고 입력한다
응답 흉내
API 응답을 가짜로 넣어 본다(GQL·REST) — 실제 신청·결제 없이
사람 단계
보이는 창에서 사람이 한 단계 진행(본인인증 등)
수동
서버 설정·계정 상태가 필요해 자동화 밖
(있음 NN)
씬 NN 으로 이미 자동화됨 — 필터 "자동화됨"
