# 에이전트 모니터 띄우기

인자: $ARGUMENTS

## 동작
`scripts/monitor-pane.sh [분]` 을 실행한다. **코드나 문서를 수정하지 않는다.**

- 인자가 숫자면 그대로 넘긴다 (`/monitor 30` → 최근 30분)
- 숫자가 아니거나 비어 있으면 인자 없이 실행 (기본 120분)
- 스크립트는 같은 워크스페이스에 `🛰 에이전트 모니터` pane 이 이미 있으면 **새로 만들지 않고 그 pane 에서 다시 실행**한다
- 새로 연 pane 에 모니터할 로그가 없으면 10초 카운트다운 후 그 pane 이 스스로 닫힌다 (`Ctrl+C` 로 취소, `MONITOR_AUTOCLOSE_SEC` 으로 초 변경, `0` 이면 안 닫음). 재사용한 pane 은 닫지 않는다
- 표준출력의 pane id 를 그대로 사용자에게 알린다. `(재사용)` 이 붙어 있으면 그 사실도 한 줄로 전한다
- stderr 에 `⚠️` 나 "herdr 밖입니다" 가 나오면 그 문장을 그대로 전한다

## 보여주는 것
`~/.claude/projects/*/*/subagents/agent-*.jsonl` 중 최근 N분 안에 수정된 것들을 tail 한다.
한 줄 = `[라벨] 도구 · 요약` 이고, 라벨은 각 에이전트의 첫 프롬프트에서 뽑은 대상 레포/앱이다.

## 보고
- pane id 한 줄과 "작업이 끝나면 프로세스가 종료되고 셸로 돌아온다"는 점만 답한다
- 로그 내용을 요약해 옮겨 적지 않는다. 사용자가 pane 에서 직접 본다
