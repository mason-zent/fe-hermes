# 현황판

인자: $ARGUMENTS

## 동작
`scripts/board.sh [stop|url|open <계획서>]` 을 실행한다. 이 스킬 자체는 코드나 문서를 수정하지 않는다(쓰기는 사용자가 화면에서 한다).

- 인자 없음: 서버가 없으면 herdr pane `📋 현황판` 에 띄우고 브라우저를 연다. 이미 떠 있으면 브라우저만 연다
- `stop`: 서버를 끈다 · `url`: 주소만 출력
- 표준출력의 주소와 pane 을 한 줄로 전한다. `⚠️` 가 나오면 그대로 전한다

## 보여주는 것 (3초마다 모아 바뀌면 화면에 밀어 준다)
| 영역 | 어디서 읽나 |
|---|---|
| 지금 동작 중 | `herdr pane list` 의 에이전트 pane(`agent_status`), 최근 30분 백그라운드 서브에이전트 로그 |
| 칸반 — 이슈 | `issues/*.md` (`status: open`) |
| 칸반 — 계획·진행 중·리뷰·완료 | `plans/**/*.md` Checkpoint 의 `Status`(planned · in_progress/blocked · ready_for_review · done). 이슈에 연결된 계획서는 이슈 카드 안에 합친다. `archive/` 는 보이지 않는다 |
| [QA] 탭 — QA 시뮬레이션 런 | `.qa-runs/` 런 목록(최신순) → 런 하나의 영향 화면 카드(판정 · 작업/기준/차이 스크린샷 · 문제 원문 · 리포트 링크). 돌고 있으면 1.5초마다 갱신. 계획서 카드(진행 중·리뷰)의 [QA 실행] 은 헤르메스를 거치지 않고 서버가 Work ref 워크트리로 `scripts/qa/run.mjs` 를 돌린다 — 한 번에 하나, 파일럿 refund-web(`scripts/qa/routes/<앱>.json` 이 있는 앱만) |
| [헤르메스] 탭 — 할 일·진행 중·완료 | `repo: hermes` 이슈와 hermes 계획서(`Agent: hermes` 또는 `Work ref` 가 `hermes …` — 서비스 칸반에서 빠진다). [처리 시작]은 디스패치 없이 헤르메스가 직접 고친다. 완료 기준은 `fix:` 커밋이 `origin/main` 에 있는 것. 서비스 칸반과 서로 끌어 옮기지 않는다 |
| 워크트리 | `.worktrees/*/*` 브랜치·미커밋 수 |

에이전트 pane 이름(`🤖 <에이전트> · <브랜치>`)의 브랜치가 계획서 `Work ref` 에 있으면 그 카드에 에이전트 배지가 붙는다.

## 화면에서 할 수 있는 것
| 동작 | 무엇이 바뀌나 |
|---|---|
| 카드를 다른 칸으로 끌어다 놓기 | 이슈는 frontmatter `status`, 계획서는 Checkpoint `Status`·`Updated` — **md**(정식 계획서면 html 결정 콘솔의 plan-md 사본도). archive 계획서는 옮기지 않는다 |
| **[아카이브]** (완료 칸 카드) | 끝난 일을 보드에서 치우고 **`archive/<이름>/` 한 폴더**로 묶는다 — `issue.md` · `plan.md`(· 정식이면 `plan.html`) · `meta.json`(보관 시각·원래 경로), 서로 가리키는 경로도 새 위치로. 이슈 워크트리 정리. `archive/` 는 git 에 커밋한다(`scripts/board/archive.mjs`) |
| **[히스토리]** 탭 | 보관한 일을 월별로 — 제목·요약·레포·커밋 검색, 이슈/계획서·레포 필터. 한 건을 누르면 이슈·요청·진행·결과·검증·커밋이 한 화면에 (`#history` 로 바로 열림) |
| **[삭제]** (완료 칸 밖 카드) | 휴지통 `.board-trash/<날짜>/` 로 옮긴다(gitignore). 이슈면 연결 경량 계획서·워크트리도. 되살릴 수 있게 지우지 않는다. 떠 있는 에이전트 pane 은 닫지 않는다 |
| 액션 버튼(처리 시작 · 진행 지시 · 이어서 진행 · 리뷰 요청 …) · 직접 지시 — 완료 칸 카드에는 없고 [아카이브] 만 있다. 이슈 [처리 시작]은 기본이 **헤르메스**(처리)이고, 팝업에서 **담당 에이전트로 바로(조사만 · 코드 수정 없음)** 로 바꿀 수 있다 | 받는 곳(카드에 붙은 에이전트 pane, 없으면 헤르메스 pane — 팝업 안에서 바꿀 수 있다)에 지시문을 입력한다(`herdr pane send-text` + Enter). **보내기 전에 창에서 보여주고 고칠 수 있다** |

- 카드는 원본 파일을 따라 움직인다. 헤르메스가 Checkpoint 를 갱신해도 같이 옮겨 간다
- 보안: 서버를 띄울 때마다 만드는 토큰과 Origin(`localhost:<포트>`)이 맞는 요청만 쓰기를 받는다. 지시는 헤르메스·위임 에이전트 pane 에만 보낼 수 있다
- 헤르메스가 작업 중일 때 보낸 지시는 지금 일이 끝난 뒤 이어서 처리된다
- 정식 계획서 카드의 **결정 콘솔 열기** — 현황판 주소로 열린 콘솔에서 고르고 **[이대로 진행]** 을 누르면 결정이 그 계획서를 만든 헤르메스 pane(`PLAN.hermesPane`)에 입력된다. 헤르메스는 `scripts/board.sh open <md>` 로 같은 주소를 연다

## 완료 가능 배지
이슈 카드는 `issues/README.md` "완료 기준" 의 신호(이슈 파일 push · 확인 결과 · 후속 정리 · fix 커밋 · 계획 done+PR MERGED · reason)를 기계적으로 확인해 전부 채워지면 `완료 가능` 이 붙는다. 진행 중 카드에는 조건 체크리스트가 보인다.
- **완료로 옮기는 건 사람이다** — 사용자가 직접 옮기거나, 사용자 지시로 헤르메스가 옮긴다. 헤르메스는 조건이 채워졌다고 알리기만 한다
- 조건이 덜 찬 카드를 완료로 옮기면 남은 조건을 보여 주고 다시 묻는다. 이슈 워크트리가 있으면 지울지도 묻는다(미커밋 변경이 있으면 지우지 않는다)
