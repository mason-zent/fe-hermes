# 가이드

인자: $ARGUMENTS

파일을 수정하지 않는다. 인자에 따라 하나만 한다.

| 인자 | 동작 |
|---|---|
| 없음 / `pane` / `메뉴` | `scripts/guide-pane.sh` — 현재 pane 오른쪽에 선택형 메뉴(`scripts/guide-menu.sh`)를 띄운다. 스킬 목록·실행 · 에이전트·담당 레포·라우팅 · git 현황·진행 중 계획서 · 시작하기 가이드 · 플레이북 · 다이어그램 · 서비스 맵 · 확장 가이드. 클릭 또는 ↑/↓·숫자 + Enter, `q` 로 닫는다 (herdr `pane split` · tmux `split-window` · 둘 다 아니면 새 Ghostty 창) |
| `<파일>` / `pane <파일>` | **실제로 있는 경로일 때만** 메뉴 대신 그 파일을 뷰어로 띄운다(예: `CLAUDE.md`). 없는 경로·일반 단어(`스킬`·`팀` 등)면 아래 "그 밖의 질문"으로 처리한다 |
| `열기` / `open` | `open docs/playbook.html` — 플레이북을 브라우저로. 열었다는 한 줄만 답한다 |
| `시작하기` / `온보딩` | `open docs/onboarding.html` — 시작하기 가이드(원본 `ONBOARDING.md`)를 브라우저로. 열었다는 한 줄만 답한다 |
| `그림` / `다이어그램` | `open docs/diagrams/index.html` — 다이어그램 목록(작업 흐름 경량·정식 + 서비스 10개 × 구조·화면 맵·요청 흐름, 비즈넵 웹 5개·모바일 앱은 심층). 열었다는 한 줄만 답한다 |

그 밖의 질문(어느 에이전트가 무엇을 하나, 작업 흐름, 스킬·에이전트 추가 방법)은 메뉴를 띄우지 말고 `AGENTS.md`·`CLAUDE.md`·`docs/extending.md` 에서 해당 절을 찾아 그대로 보여 주고 원본 경로를 한 줄 덧붙인다.
