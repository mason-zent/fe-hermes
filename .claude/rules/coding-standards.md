# 공통 코드 규칙

정본은 `docs/knowledge/common/coding.md`(팀 공통) → `docs/knowledge/<레포>/rules.md`(레포) → 레포 원문 문서 순이며 뒤가 우선한다. 아래는 헤르메스가 늘 기억할 요약.

## 작업 원칙
- 작업 전 반드시 기존 코드 패턴을 분석하고 그 패턴을 따른다
- 요청 범위 밖의 대규모 정리, 의존성 업그레이드, 파일 이동, 전역 포맷팅 금지
- 포맷은 **작업한 파일만** 적용 (`prettier --write <파일>`)
- 각 에이전트는 자신의 담당 레포 안에서만 수정한다. 다른 레포·공유 패키지 수정이 필요하면 헤르메스에 보고한다

## 변수명 / 가독성
- 1개 문자 변수명 금지 (반복문 변수 포함)
- 3항 연산자 중첩 금지. 필요하면 별도 함수로 분리
- 새 코드에서 `any` 금지. `unknown`으로 받아 narrowing
- 이번 변경으로 생긴 미사용 import·변수·함수는 정리한다. 기존 미사용 코드는 요청 범위일 때만 지우고, 아니면 보고·`issues/` 등록

## 단순한 구현
- 현재 요구에 필요 없는 범용화·옵션·prop 을 추가하지 않는다. 가독성·테스트·기존 패턴을 위한 분리와 필수 상태·오류 처리·외부 입력 검증·보안 처리는 유지한다. 상세는 `docs/knowledge/common/coding.md` "단순한 구현"

## 성능
- O(n²) 이상 로직, 2중 이상 반복문은 재검토 대상

## 오류 대응
- 같은 오류 3회 반복 시 접근 방식을 전면 재검토하고 헤르메스에 보고

## 보안
- `.env*`, 토큰, 키 파일 내용은 출력·커밋하지 않는다
- **토큰·키·비밀번호는 무조건 노출 금지.** 값은 어떤 경로로든 출력하지 않는다 — 파일 읽기(`.npmrc`·`.env*`·키 파일, `git show/diff/log` 포함), `npm/pnpm/yarn config get·list`, `printenv`·`env`, 프로세스 전체 인자(`pgrep -fl`·`ps aux`·`ps -ef` — 환경 변수가 섞여 나온다, `ps -axo pid=,comm=` 만), `echo $…TOKEN`, `gh auth token`, 로그·보고·커밋 메시지·계획서 모두. 확인이 필요하면 **있는지·참조 형태(`${…}`)·길이·HTTP 상태 코드만** 본다(`curl -s -o /dev/null -w '%{http_code}'`). 봐야 하면 `sed 's/_authToken=.*/_authToken=***/'` 로 가린 뒤. 실수로 노출되면 즉시 멈추고 사용자에게 알려 폐기·재발급을 권한다. 모든 세션(헤르메스·FE·reviewer)에 `scripts/hooks/secret-guard.py` 가 걸려 흔한 경로를 막는다(보안 경계는 아니다 — 규칙이 우선)
